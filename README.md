# MedApp

Курсовая работа: система учёта домашней аптечки. Мобильное приложение для Android и серверная
часть; аптечки бывают общими — семья, соседи. Система приватна по замыслу: о человеке не хранится
ничего, кроме идентификатора и хеша ключа.

## Структура

```
MedApp/
├── docs/                     # Документация курсовой работы
│   ├── Final/                # Финальные версии (PDF)
│   └── WorkInProgress/       # Рабочие версии
└── src/
    ├── MedAppServer/         # Серверная часть: Kotlin, Spring Boot 4, PostgreSQL
    ├── AndroidApp/           # Мобильное приложение (Android)
    └── scrapper/             # Скраппер справочника лекарств vidal.ru (Python)
```

## Части

### Сервер — [src/MedAppServer](src/MedAppServer)

REST API: аптечки и участники, упаковки, брони, справочник, синхронизация офлайн-изменений.

- [README](src/MedAppServer/README.md) — что умеет, как запустить, перечень эндпоинтов
- [ARCHITECTURE.md](src/MedAppServer/ARCHITECTURE.md) — как устроен: модель, слои, доступ,
  конкурентность, синхронизация
- [ARCHITECTURE-RULES.md](src/MedAppServer/src/test/kotlin/org/kert0n/medappserver/ARCHITECTURE-RULES.md)
  — правила и то, чем каждое закреплено
- [open-api.yaml](src/MedAppServer/open-api.yaml) — контракт целиком, читается без запуска
- [db/schema.sql](src/MedAppServer/db/schema.sql) — схема базы; порождается из описания таблиц

### Мобильное приложение — [src/AndroidApp](src/AndroidApp)

Клиент для Android: копит изменения офлайн и синхронизируется с сервером.

### Скраппер — [src/scrapper](src/scrapper)

Собирает справочник препаратов с vidal.ru. Работает мимо приложения: сервер справочник только
читает.
